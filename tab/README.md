# Подсказка следующего шага по Tab

Отдельный плагин для BetterGravity 3.0.0 и самостоятельного Antigravity 2.29.0. Русификатор для работы плагина не требуется. Плагин использует локальные правила по последнему ответу и не отправляет запросы к модели. Он не является языковой моделью и показывает подсказку только в некоторых ситуациях.

Подсказка появляется в пустом поле диалога. Tab вставляет ее как редактируемый черновик без отправки, Escape скрывает. Ввод через @ и другие открытые меню сохраняют обычное поведение Tab.

## Установка

1. Установите BetterGravity и включите режим разработчика плагинов в его настройках. Этот режим разрешает запуск JavaScript плагинов, поэтому устанавливайте только исходники, которым доверяете.
2. Откройте настройки BetterGravity, выберите импорт плагина и укажите папку `tab` с файлами `plugin.json` и `index.js`. Либо скопируйте эту папку в каталог плагинов BetterGravity и включите ее в настройках.
3. Откройте диалог с ответом агента и поставьте курсор в пустое поле.

Если ранее у вас была экспериментальная сборка русификатора со встроенным Tab, сначала обновите русификатор до этого выпуска. Иначе могут одновременно работать два обработчика клавиши.

Для удаления выключите плагин в настройках BetterGravity и удалите только его папку. Плагин отключает обработчики и убирает свою подсказку при остановке.

Плагин читает последний отображаемый ответ локально, чтобы предложить продолжение. Сообщения, историю, токены, файлы и настройки он не отправляет наружу и не записывает. Подсказка остается предложением, проверяйте ее перед отправкой. При неизвестном состоянии плагин может не показывать подсказку.
