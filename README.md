# Локальный русификатор Antigravity 2.31.2

Неофициальный локальный патч интерфейса. Он не является выпуском Google.

Отдельный плагин подсказок по Tab находится в [папке tab](tab/README.md). Он устанавливается независимо от русификатора через BetterGravity.

Выпуск `v2.31.2-r2` поддерживает Antigravity 2.31.2 и содержит 5883 записи словаря. Переведены новые подсказки Orchestrator, пункт «Версия 2.31.2», настройки, контекстные меню, встроенный браузер, подключения, голосовой режим и автоматизации. Исправлены подписи, у которых раньше переводилось только первое слово.

Структурный офлайн-аудит точного кода 2.31.2 проверяет 2667 строк интерфейса и 311 составных шаблонов. Из строк 2581 переводится целиком, 12 коротких фрагментов переводятся только в соответствующем контексте, 74 технических обозначения и фрагмента кода сохраняются. Среди шаблонов 281 покрыт переводом, а 30 относятся к значениям, синтаксису или внутренним инструкциям агента. Новая неизвестная строка, неполный перевод по общему префиксу или изменение проверенного исходного кода останавливают этот аудит.

Системные подсказки моделей проверяются отдельно во всех доступных окнах приложения, включая HTTPS-окна. В r2 также добавлены русские описания 17 известных навыков. Это отображаемые краткие описания в каталоге: идентификаторы, файлы и исходные инструкции навыков не меняются.

Сохраняются сообщения, рассуждения, код, команды, вывод инструментов и исходные инструкции навыков. Названия моделей и их режимов остаются по-английски. Статус выполнения Thinking переводится как «Думает», режим модели Thinking сохраняется. Анимированные подписи и числовые коды завершения покрыты отдельными проверками.

Правило [русского языка](examples/russian-visible-reasoning.md) для новых видимых рассуждений включается отдельно. Оно не переводит старый текст и не гарантирует язык рассуждений сервиса. Патчер не устанавливает переводчики и не меняет правило автоматически. Нативные уведомления с генерируемым резюме агента остаются вне области DOM-перевода.

Аудиты читают только статический код либо системные метаданные уже загруженных моделей и карточек. Они не запускают приложение, не открывают меню и не читают переписку, введенные значения, ключи или сведения о лимитах. Отсутствие загруженных данных означает неполное покрытие.
## Подготовка

Нужен Node.js **22.12+ из ветки 22.x**. Зависимость `@electron/asar` зафиксирована в `package-lock.json`; автоматическое скачивание через `npx -y` не используется.

В корневой папке пакета один раз выполните:

```bash
npm ci
npm test
```

`npm ci` устанавливает ровно версии из lock-файла и не запускает сценарии зависимостей. Если проверка не проходит, не применяйте патч к Antigravity.

После установки создается `install-manifest.json`, который игнорируется Git. Для автоматизированной проверки его можно направить в отдельный абсолютный путь через переменную `ANTIGRAVITY_RU_MANIFEST_PATH`.

Перед изменением `localize-antigravity-ru.js` сохраняет исходный `app.asar` как `app.asar.antigravity-ru-original.bak` в той же директории. Если в установленной версии есть соседняя папка `app.asar.unpacked`, скрипт сначала сверяет ее с архивом, сохраняет исходную схему распакованных файлов при пересборке и останавливается до замены архива при любом несовпадении. Закройте Antigravity перед установкой, проверкой или откатом.

Обновление Antigravity заменяет `app.asar` и сбрасывает русификацию. После обновления используйте выпуск русификатора для новой версии приложения и повторите установку; старый патчер остановится при несовпадении версий.

BetterGravity для русификатора не требуется и автоматически не устанавливается. Для Windows предусмотрена совместимость с уже установленной проверенной оболочкой BetterGravity 3.0.0: русифицируется внутренний архив приложения, а оболочка и нативные ресурсы сохраняются. Незнакомые варианты оболочки отклоняются до изменения файлов. Отдельному необязательному Tab-плагину из папки `tab` BetterGravity необходим.

## Windows

Стандартная установка находится в `C:\Users\<имя>\AppData\Local\Programs\antigravity\resources`.

```powershell
node localize-antigravity-ru.js --inspect
node localize-antigravity-ru.js
node localize-antigravity-ru.js --verify
```

Откат:

```powershell
node localize-antigravity-ru.js --restore
```

## Linux

Официальные сборки x64 и ARM64 поддерживаются одинаково: русификатор изменяет JavaScript-архив приложения и не зависит от архитектуры процессора. Удобный установщик сам проверяет Node.js, при необходимости выполняет `npm ci --ignore-scripts`, находит приложение, не позволяет менять файлы запущенной Antigravity и после установки выполняет полную проверку:

```bash
chmod +x scripts/install-linux.sh scripts/install-unix.sh
./scripts/install-linux.sh inspect
./scripts/install-linux.sh install
```

Проверка и откат:

```bash
./scripts/install-linux.sh verify
./scripts/install-linux.sh restore
```

Для системной установки установщик сам вызывает `sudo` только для патчера. Зависимости всегда устанавливаются заранее от имени обычного пользователя.

Поддержаны официальные DEB/RPM-пакеты, распакованный tarball и пользовательские установки. Скрипт автоматически ищет `app.asar` в:

```text
/opt/antigravity/resources
/opt/Antigravity/resources
/opt/Antigravity/Antigravity-x64/resources
/opt/Antigravity/Antigravity-arm64/resources
/usr/share/antigravity/resources
/usr/lib/antigravity/resources
/usr/lib64/antigravity/resources
~/.local/opt/antigravity/resources
~/.local/opt/Antigravity/resources
~/.local/share/antigravity/resources
~/.local/share/Antigravity/resources
~/Applications/antigravity/resources
~/Applications/Antigravity/resources
```

Если Antigravity распакован в другую директорию, явно передайте абсолютный путь ровно к папке `resources`:

```bash
./scripts/install-linux.sh inspect --resources="$HOME/Applications/Antigravity/resources"
./scripts/install-linux.sh install --resources="$HOME/Applications/Antigravity/resources"
```

AppImage не изменяется в работающем смонтированном образе. Распакуйте его в постоянную директорию либо используйте tarball-установку, затем укажите папку `resources`.

## macOS

Поддерживаются Apple Silicon и Intel начиная с macOS 12 — код русификатора одинаков для обеих архитектур. Поддерживается самостоятельное приложение `Antigravity.app`, а не отдельная Antigravity IDE с распакованной структурой файлов. Скрипт ищет:

```text
/Applications/Antigravity.app/Contents/Resources
~/Applications/Antigravity.app/Contents/Resources
```

Закройте Antigravity, сделайте установщики исполняемыми и запустите:

```bash
chmod +x scripts/install-macos.command scripts/install-unix.sh
./scripts/install-macos.command inspect
./scripts/install-macos.command install
```

Проверка и откат:

```bash
./scripts/install-macos.command verify
./scripts/install-macos.command restore
```

Если приложение находится в `/Applications`, установщик сам запросит права администратора для изменения этой копии. Явный путь с правильным для macOS регистром также поддержан:

```bash
./scripts/install-macos.command install --resources=/Applications/Antigravity.app/Contents/Resources
```

После установки и отката скрипт автоматически применяет локальную ad-hoc подпись через системный `codesign`, сохраняет доступные метаданные предыдущей подписи и проверяет всю структуру приложения командами `--deep --strict`. Она заменяет подпись Google только у измененной локальной копии приложения; следующая официальная установка или обновление вернет исходный `app.asar`.

Ручные команды для диагностики остаются доступны на обеих системах:

```bash
node localize-antigravity-ru.js --resources=/absolute/path/to/resources --inspect
node localize-antigravity-ru.js --resources=/absolute/path/to/resources --verify
```

CI запускает одинаковые проверки словаря и структуры на Windows, Linux и macOS. На Linux и macOS дополнительно создается синтетическая Electron-установка, после чего проверяется полный цикл `install → verify → restore`; в macOS в этот цикл входит локальная подпись и ее строгая проверка. Реальный интерфейс все равно нужно визуально проверить на целевой машине после запуска приложения.

Основа словаря получена из статических блоков `DICT` MIT-проекта `j46871417-ui/Antigravity-Localizer` (commit `8a6954cd1852397e893e9e60f08dea3f1f92fb35`). Дополнительные переводы настроек и динамические шаблоны написаны локально. Правила и функции онлайн-перевода стороннего проекта не используются. Публичный пакет не содержит исходников, словарей или ресурсов других русификаторов; происхождение и границы сторонних материалов описаны в `PROVENANCE.md` и `THIRD_PARTY_NOTICES.md`. Точки встраивания отдельно проверяются для Antigravity 2.31.2.

Для пересборки словаря укажите оба файла-источника явно:

```powershell
node build-static-dictionary.js <путь-к-dom_translator.js> <путь-к-i18n-ru.js>
```
